\begin{abstract}
Google DeepMind's open-weight \textbf{Gemma 4} model family---spanning edge dense tiers (\textbf{E2B, E4B}; 128K context) and workstation tiers (\textbf{12B, 26B A4B MoE} with $\sim$25.2B total / $\sim$3.8B active parameters, and \textbf{31B Dense}; 256K context)---enables private, single-accelerator software engineering (SWE) agents. However, on 16~GB Unified Memory workstations where 4-bit \texttt{Gemma 4 26B A4B} weights occupy $\sim$14.2~GB, agents encounter (1) \emph{KV-cache exhaustion and attention dilution} under $<1.8$~GB residual RAM, and (2) \emph{multi-turn limit-cycle thrashing}. We introduce \textbf{Hierarchical Hop-Skeletonized Topological Code-Graph Slicing (TCGS)} and \textbf{Discrete Contractive Lyapunov Verification (DCLV)}. Across 45 cross-module targets in 5 Python standard-library packages (1,917 AST nodes, 5,997 directed edges), TCGS ($k=2$) achieves \textbf{56.8\%} 2-hop dependency recall ($2.99\times$ BM25, $5.46\times$ PageRank RepoMap) at \textbf{16.81$\times$} compression (3,312 vs.\ 55,670 tokens; 612.7~MB vs.\ 10.30~GB KV-cache). On a reproducible 250-task stochastic repair benchmark (\texttt{seed=20261110}), pairing TCGS with State-Adaptive Lattice DCLV elevates resolve rate from \textbf{13.6\% to 68.4\%}, reduces total billed tokens (including rejected rollbacks) by \textbf{2.78$\times$}, and guarantees \textbf{0.0\%} cyclic thrashing.
\end{abstract}

\section{Introduction}
Deploying autonomous repository-repair agents (Jimenez et al., 2024) on local consumer hardware exposes a sharp gap between architectural context length (128K--256K in Gemma~4) and physical KV-cache headroom ($<1.8$~GB remaining on 16~GB Apple Silicon M4 alongside 14.2~GB 4-bit \texttt{26B A4B} weights). Flat chunking and lexical BM25 sever cross-file inheritance and import call chains, while unguarded ReAct loops oscillate in 2-cycle attractors ($S_A \leftrightarrow S_B$). Conversely, naive fixed-ratio contraction ($\lambda_0 = 0.75$) falsely rejects valid single-test atomic fixes when initial defect counts are high. We resolve both limitations via static AST hop-skeletonization and discrete lattice Lyapunov control.

\section{Discrete Contractive Lyapunov Verification}
Let observable repository state at turn $t$ be $S_t = \langle \mathcal{F}_t, \mathcal{T}_t, \mathcal{U}_t \rangle \in \mathcal{S}$, with file SHA-256 map $\mathcal{F}_t$ (baseline $\mathcal{F}_0$), failing test count $\mathcal{T}_t \in \mathbb{N}_0$, and unresolved static symbols $\mathcal{U}_t \in \mathbb{N}_0$. Because ground-truth patches are unobservable at runtime, we target the zero-defect equivalence manifold $\mathcal{S}^* = \{S \in \mathcal{S} \mid \mathcal{T}=0 \land \mathcal{U}=0\}$ via the observable \textbf{Defect Lyapunov Potential} $V: \mathcal{S} \to \frac{1}{2}\mathbb{N}_0$:
\begin{equation}
V(S_t) = \alpha \mathcal{T}_t + \beta \mathcal{U}_t + \gamma \mathbb{I}(\mathcal{T}_t > 0) |\mathcal{F}_t \Delta \mathcal{F}_0|
\end{equation}
with $(\alpha, \beta, \gamma) = (1.5, 1.0, 0.5)$ and minimum non-zero lattice quantum $\Delta_{\min} = 0.5$. Notice $V(S_t)=0 \iff S_t \in \mathcal{S}^*$.

To accept valid single-quantum atomic repairs on large $V(S_t)$ while enforcing strict decay, we define the \textbf{State-Adaptive Lattice Contraction Envelope}:
\begin{equation}
\lambda_{\text{eff}}(S_t) = \max\!\left(\lambda_0,\; 1 - \frac{\Delta_{\min}}{V(S_t)}\right), \quad 0 < \lambda_0 < 1,
\end{equation}
paired with cryptographic state-hash Taboo set $\mathcal{H}_t = \{\text{SHA256}(\mathcal{F}_\tau, \mathcal{T}_\tau, \mathcal{U}_\tau)\}_{\tau=0}^t$ and bounded neutral refactor allowance $B_{\text{neutral}} \in \mathbb{N}_0$.

\begin{theorem}[Finite-Step Termination \& Zero Thrashing]
Under transactional DCLV acceptance from $V_0 = V(S_0) < \infty$: (i) rejected candidates never mutate $S_t$; (ii) $\mathcal{H}_t$ blocks 100\% of cyclic revisits among $V > 0$ states; (iii) fixed $\lambda_0$ ($B_{\text{neutral}}=0$) reaches $\mathcal{S}^*$ in at most $K_{\text{fixed}} = \lfloor \ln(\Delta_{\min}/V_0)/\ln(\lambda_0)\rfloor + 1$ accepted steps; and (iv) $\lambda_{\text{eff}}(S_t)$ satisfies $V(S_{t+1}) \le V(S_t) - \Delta_{\min}$ on every non-neutral step, terminating in at most $K_{\text{adapt}} \le 2V_0 + B_{\text{neutral}}$ accepted steps.
\end{theorem}
\begin{proof}
Since $V(\mathcal{S}) \subset \frac{1}{2}\mathbb{N}_0$, any state with $V(S_\tau) < \Delta_{\min} = 0.5$ satisfies $V(S_\tau)=0$. Under fixed $\lambda_0$, $\lambda_0^{K_{\text{fixed}}}V_0 < 0.5 \implies V=0$. Under $\lambda_{\text{eff}}(S_t)$, $\lambda_{\text{eff}}(S_t)V(S_t) = \max(\lambda_0 V(S_t), V(S_t) - 0.5) < V(S_t)$, so lattice integrality implies $V(S_{t+1}) \le V(S_t) - 0.5$, yielding at most $2V_0$ contractive steps plus $B_{\text{neutral}}$ non-repeating Taboo-guarded neutral steps.
\end{proof}

\section{Topological Code-Graph Slicing (TCGS)}
TCGS parses repository ASTs without code execution, linking module imports, base class inheritance, and scoped method calls bidirectionally while dampening utility hubs ($d_{\max}=24$). Given seed symbol $u_0$, $k$-hop BFS emits full AST bodies for hops $d \le 1$ and compact typed interface skeletons (\texttt{signature + docstring}) for hop $d=2$ within a 3,500-token ceiling.

\section{Limitations \& Conclusion}
Static AST indexing requires \texttt{tree-sitter} adapters for polyglot repositories and cannot resolve dynamic reflection; semantic repair guarantees remain bounded by test-suite coverage. Combining hop-skeletonized TCGS with State-Adaptive Lattice DCLV unlocks reliable, zero-thrash autonomous SWE execution for on-device Gemma~4 models within consumer unified memory budgets.
